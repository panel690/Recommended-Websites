FMHY（FreeMediaHeckYeah / fmhy.net）は、「インターネット最大の無料リソース集」を掲げるコミュニティ運営のWiki型リンク集です。
コンテンツ自体をホストするのではなく、動画、音楽、読書、ゲーム、学習、ソフトウェア、AIツールなど、分野ごとに厳選された外部サイトへのリンクを整理して紹介しています。
膨大な情報がカテゴリとおすすめ度で整理されているため、目的の無料サービスやツールを探すときの入口として便利です。

Wotaku（wotaku.wiki）は、「The Otaku Index」を掲げる、オタク文化に特化したドキュメント型リンク集です。
アニメやマンガを読む・観るためのサイトだけでなく、ライトノベル、音楽・サウンドトラック、ゲーム、VTuber関連のツールやガイドまでを整理して紹介しています。
FMHYがあらゆるジャンルを扱う総合リンク集なのに対して、Wotakuは日本メディアとオタク趣味に絞っているため、目的のサイトをアニメ・マンガ寄りで探したいときに便利です。

AlternativeTo（alternativeto.net）は、「今使っているソフトが高すぎる」「終了してしまった」「もっと軽いものがほしい」というときに、代替アプリを探すためのサイトです。
検索したアプリに対して、ユーザーの「Like」やレビューをもとにランク付けされた代替候補が一覧で表示されます。各候補には対応プラットフォーム、ライセンス（無料／有料／オープンソース）、概要がまとまっているため、乗り換え先を比較しやすくなっています。
FMHYやWotakuが「分野ごとのリンク集」なのに対して、AlternativeToは「1つのアプリ → その代わり」という探し方に特化しています。
